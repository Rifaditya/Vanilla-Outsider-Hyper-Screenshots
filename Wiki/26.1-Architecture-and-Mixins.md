## 3. Mixin Injection Target Specification

### `GameRendererMixin.java`
* **Target Class**: `net.minecraft.client.renderer.GameRenderer`
* **Injection 1**: `@Inject(method = "renderItemInHand", at = @At("HEAD"), cancellable = true)`
  * Suppresses first-person hand rendering during active capture pass when `autoHideHand` is enabled.
* **Injection 2**: `@Inject(method = "render", at = @At("RETURN"))`
  * Detects when a capture request is pending and invokes `HyperCaptureManager.getInstance().executePendingCapture(this.minecraft, deltaTracker)` immediately after normal frame rendering.

### `KeyboardMixin.java`
* **Target Class**: `net.minecraft.client.KeyboardHandler`
* **Method Signature**: `keyPress(long handle, int action, KeyEvent event, CallbackInfo ci)`
* **Injection Point**: `@Inject(method = "keyPress", at = @At("HEAD"), cancellable = true)`
* **Behavior**:
  * Intercepts `KEY_F2` (`291`).
  * If `Alt` modifier is active: toggles Auto-Hide Hand, saves config, and cancels vanilla screenshot.
  * If `Ctrl` modifier is active and `instantMaxKeyEnabled` is true: queues `ResolutionPreset.SIXTEEN_K` capture and cancels vanilla screenshot.
  * If configured preset is not `NORMAL`: queues supersampled capture pass and cancels vanilla screenshot.
  * If preset is `NORMAL`: allows vanilla screenshot pipeline to proceed untouched.

  [Toggle Hand] [16K Capture] [Active Preset]
