## 2. Step-by-Step Player Workflow

### Option A: Using the Graphical Configuration Screen (GUI)
1. Open the Minecraft **Options** menu.
2. Click **Mods** (ModMenu) and select **Hyper Quality Screenshots**.
3. Click the gear / config button to open the **YACL Settings Screen**.
4. Adjust resolution presets, enable Auto-Hide HUD, or set custom multipliers.
5. Click **Done** to save changes atomically to disk.

### Option B: Using In-Game Hotkeys
* **`F2`**: Capture screenshot using active configured preset.
* **`Ctrl + F2`**: Instant 16K QUHD snapshot (bypasses active preset).
* **`Alt + F2`**: Live toggle Auto-Hide Hand on/off with chat confirmation.

### Option C: Using Brigadier Client Commands
* View current configuration: `/hyperscreenshots status`
* Switch preset to 8K: `/hyperscreenshots preset 8k`
* Toggle HUD hiding: `/hyperscreenshots toggle hud`
* Trigger capture from chat: `/hyperscreenshots capture`

## 3. Resolution Presets Reference Table

| Preset Enum | In-Game Display Name | Target Height | Scale Multiplier | Default Suffix | Notes |
| :--- | :--- | :---: | :---: | :---: | :--- |
| `NORMAL` | `Normal (Native)` | -1 | $1.0\times$ | `_native` | Uses Minecraft's default window resolution |
| `TWO_K` | `2K QHD (1440p)` | 1440 | $1.33\times$ | `_2k` | Crisp QHD output with low performance cost |
| `FOUR_K` | `4K UHD (2160p)` | 2160 | $2.0\times$ | `_4k` | **Default preset**: Ideal balance of quality and speed |
| `EIGHT_K` | `8K FUHD (4320p)` | 4320 | $4.0\times$ | `_8k` | High-fidelity billboard print quality |
| `SIXTEEN_K` | `16K QUHD (8640p)` | 8640 | $8.0\times$ | `_16k` | Extreme resolution via $4\times 4$ tiled rendering |
| `CUSTOM` | `Custom Multiplier` | Dynamic | $1.0\times - 16.0\times$ | `_custom` | User-defined slider scale in steps of 0.5x |

## 5. JSON Configuration Schema

Located at `.minecraft/config/hyper_screenshots.json`:
```json
{
  "resolutionPreset": "FOUR_K",
  "customMultiplier": 2.0,
  "autoHideHud": false,
  "autoHideHand": false,
  "instantMaxKeyEnabled": true,
  "playSoundOnSuccess": true,
  "hardwareTransparencyAlerts": true
}
```

| JSON Field | Data Type | Default Value | Description |
| :--- | :---: | :---: | :--- |
| `resolutionPreset` | String | `"FOUR_K"` | Active preset (`NORMAL`, `TWO_K`, `FOUR_K`, `EIGHT_K`, `SIXTEEN_K`, `CUSTOM`) |
| `customMultiplier` | Float | `2.0` | Custom scale multiplier applied when preset is `CUSTOM` ($1.0$ to $16.0$) |
| `autoHideHud` | Boolean | `false` | Automatically hides crosshair, hotbar, and status bars during capture |
| `autoHideHand` | Boolean | `false` | Hides player's held hand/items during screenshot pass |
| `instantMaxKeyEnabled` | Boolean | `true` | Enables `Ctrl + F2` hotkey for instant 16K QUHD capture |
| `playSoundOnSuccess` | Boolean | `true` | Plays completion chime upon successful disk write |
| `hardwareTransparencyAlerts` | Boolean | `true` | Displays chat alerts when tiled rendering or clamping engages |

## 6. Brigadier Command Specification

All commands are purely client-side registered through Fabric API (`ClientCommandRegistrationCallback`):

| Command Syntax | Parameters | Purpose |
| :--- | :--- | :--- |
| `/hyperscreenshots help` | None | Displays syntax help and hotkeys summary |
| `/hyperscreenshots status` | None | Displays active preset, multiplier, and toggle states |
| `/hyperscreenshots preset <name>` | `normal`, `2k`, `4k`, `8k`, `16k`, `custom` | Sets active resolution preset and saves to disk |
| `/hyperscreenshots capture [preset]` | Optional preset name | Triggers screenshot capture immediately |
| `/hyperscreenshots toggle <setting>` | `hud`, `hand`, `instantmax`, `sound`, `alerts` | Toggles setting on/off and displays status |
| `/hyperscreenshots reload` | None | Reloads configuration from disk |

Aliases: `/hypershot`, `/hqss`.

## 7. Developer & Addon Extension Hooks

Developers can hook into config loading and retrieval:
```java
// Access active singleton config
HyperScreenshotsConfig config = HyperScreenshotsConfig.get();
ResolutionPreset preset = config.resolutionPreset;

// Programmatically request capture
HyperCaptureManager.getInstance().requestCapture(ResolutionPreset.EIGHT_K, false);
```
