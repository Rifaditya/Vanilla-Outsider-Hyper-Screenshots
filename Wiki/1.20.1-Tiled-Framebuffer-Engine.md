## 2. Step-by-Step Player Workflow

1. **Triggering Capture**: The player presses **`F2`** (active preset) or **`Ctrl + F2`** (Instant 16K QUHD).
2. **State Interception**: `KeyboardMixin` debounces inputs and instructs `HyperCaptureManager` to queue a capture pass.
3. **Camera Frustum Slicing**: At the start of the render pass, the engine queries the active aspect ratio and splits the viewport into a grid of sub-tiles.
4. **Multi-Pass Tile Rendering**: The camera projection matrix is sheared and translated for each sub-tile, capturing high-detail geometry into an offscreen buffer.
5. **Buffer Stitching**: `TiledRenderEngine.stitchTile()` writes each sub-tile's raw RGBA pixels directly into the master `NativeImage` memory buffer.
6. **Asynchronous Dispatch**: The completed image is handed off to `Util.ioPool()` to write to disk without dropping game frame rates.

## 3. Mathematical Foundations & Formulas

### Aspect Ratio & Target Resolution
To prevent distortion, target dimensions strictly respect the current window aspect ratio $R$:
$$R = \frac{\max(W_{\text{window}}, 128)}{\max(H_{\text{window}}, 128)}$$
$$H_{\text{target}} = H_{\text{preset}}, \quad W_{\text{target}} = \text{round}(H_{\text{target}} \times R)$$
To satisfy OpenGL texture alignment and PNG scanline encoding requirements, dimensions are aligned to even integers:
$$W_{\text{even}} = W_{\text{target}} + (W_{\text{target}} \bmod 2), \quad H_{\text{even}} = H_{\text{target}} + (H_{\text{target}} \bmod 2)$$

### Frustum Shearing Projection Matrix
For a tile at column coordinate $c \in [0, C-1]$ and row coordinate $r \in [0, R-1]$ within a $C \times R$ grid, the modified projection matrix $M_{\text{tile}}$ is computed via scaling and translation in Normalized Device Coordinates:
$$M_{\text{tile}} = T\left(\frac{C - 1 - 2c}{C}, \frac{2r + 1 - R}{R}, 0\right) \cdot S(C, R, 1) \cdot M_{\text{baseProj}}$$
Where:
* $S(C, R, 1)$ scales the frustum field of view by the grid dimensions.
* $T(\Delta x, \Delta y, 0)$ shifts the view center to focus exclusively on quadrant $(c, r)$.

## 7. Developer & Mixin Hooks

### Creating Sub-Frustum Matrix
```java
// net.vanillaoutsider.hyperscreenshots.render.TiledRenderEngine
public static Matrix4f createSubFrustumMatrix(Matrix4f baseProjection, int col, int row, int cols, int rows) {
    Matrix4f subFrustum = new Matrix4f(baseProjection);
    if (cols <= 1 && rows <= 1) return subFrustum;

    float scaleX = (float) cols;
    float scaleY = (float) rows;
    float transX = (float) (cols - 1 - 2 * col);
    float transY = (float) (2 * row + 1 - rows);

    Matrix4f tileTransform = new Matrix4f();
    tileTransform.scaling(scaleX, scaleY, 1.0f);
    tileTransform.translate(transX / scaleX, transY / scaleY, 0.0f);
    return tileTransform.mul(subFrustum);
}
```

### Stitching Sub-Tiles
```java
// Copies scanlines from sub-tile NativeImage into the master image buffer
public static void stitchTile(NativeImage destination, NativeImage subTile, int col, int row, int tileWidth, int tileHeight, int totalWidth, int totalHeight) {
    int startX = col * tileWidth;
    int startY = row * tileHeight;
    int copyWidth = Math.min(tileWidth, totalWidth - startX);
    int copyHeight = Math.min(tileHeight, totalHeight - startY);
    for (int y = 0; y < copyHeight; y++) {
        for (int x = 0; x < copyWidth; x++) {
            int destX = startX + x;
            int destY = startY + y;
            if (destX < totalWidth && destY < totalHeight) {
                destination.setPixel(destX, destY, subTile.getPixel(x, y));
            }
        }
    }
}
```
