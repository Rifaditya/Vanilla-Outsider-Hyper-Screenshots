# 📷 Vanilla Outsider: Hyper Quality Screenshots

Hyper Quality Screenshots is a client-side Fabric mod that enables high-resolution screenshot captures (Normal, 2K, 4K, 8K, 16K) with offscreen framebuffer supersampling, chunked tile rendering, asynchronous non-blocking disk writes, and pure YetAnotherConfigLib (YACL v3) configuration — with strictly zero GameRules.

Part of the **Vanilla Outsider Collection** — enhancing vanilla loops while preserving 1:1 input integrity.
